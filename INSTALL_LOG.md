# Install logging (требование пользователя)

Весь процесс установки и работы пишется в лог-файлы, чтобы при сбое можно было отправить лог:

- `DSH/logs/install-<дата>.log` — мастер первого запуска: скачивание чанков, sha256, распаковка rootfs/пейлоада, старт proot/адаптера/dsh. Плюс блок `device info` (модель, Android, RAM, свободное место).
- `DSH/logs/dsh.log`, `adapter.log` — ротация 5×2 МБ.
- Экран «Логи» в приложении: просмотр + кнопка «Отправить» (системный шаринг: Telegram/почта/файл).
- При падении мастера установки — диалог «Установка не удалась» с кнопками «Отправить лог» и «Повторить».
